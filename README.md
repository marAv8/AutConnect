## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Platform administration

Agency approvals are intentionally separate from agency supervision. Configure a
comma-separated allow-list of existing AutConnect account emails before opening
`/platform/agency-requests`:

```bash
AUTCONNECT_PLATFORM_ADMIN_EMAILS="owner@example.com,security@example.com"
```

An allow-listed user must still sign in normally. If the variable is missing or
empty, nobody receives platform-administrator access. Agency requests create no
accounts or permissions until an allow-listed administrator approves them.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
